# MOSFET选型规范

## 前言：MOSFET在不同领域的差异化选型重点

| 产品类型   | 第一优先级                             | 第二优先级                                  | 第三优先级    | 备注                                                     |
| ---------- | :------------------------------------- | :------------------------------------------ | :------------ | :------------------------------------------------------- |
| 微型逆变器 | 导通电阻Rds(on) <br> 开关损耗(Qg,Coss) | 体二极管反向恢复(Qrr)<br>热阻(RθJC)         | 雪崩耐量(EAS) | 户外安装+25年寿命+散热受限<br>决定了效率优先             |
| 服务器电源 | FOM = Rds(on) * Qg<br>功率密度         | 并联均流能力<br>栅极电荷Qg                  | 体二极管性能  | 超高功率密度+钛金级效率+强制风冷<br>决定了权衡效率和密度 |
| 工业电源   | 鲁棒性(EAS,SOA)<br>长期可靠性          | 最高结温Tj(max)不低于175℃<br>宽温度范围工作 | 长期供货保证  | 恶劣环境+高可靠性+无法频繁维修<br>决定了鲁棒性优先       |


## 1.适用范围
<!--写明使用于哪些产品类型及电路位置-->
本规范适用于以下产品中的功率 MOSFET 选型：

  - **微型逆变器**：DC-DC 升压级、DC-AC 逆变级、同步整流

  - **服务器电源**：PFC 级、LLC 级、同步整流      

  - **工业电源**：PFC 级、反激式辅助电源、DC-DC 转换

适用电压等级：

- **低压 MOSFET**：< 100V（用于同步整流、低压侧开关）

- **中压 MOSFET**：100V - 300V

- **高压 MOSFET**：≥ 600V（用于 PFC、逆变桥、高压 DC-DC）

- **超高压 MOSFET**：≥ 1200V（主要用于 SiC，工业电源前级）

## 2.关键参数与优先级

### 2.1 电压参数

| 参数         | 符号     | 定义                                                       | 选型要点                                                                                         |
| ------------ | -------- | ---------------------------------------------------------- | ------------------------------------------------------------------------------------------------ |
| 漏源击穿电压 | V(BR)DSS | 是MOSFET能承受的最大漏源电压，超过该电压会导致 MOSFET 损毁 | 必须覆盖电路中所有可能的最高呀，包括正常工作电压、开关尖峰电压、负载突变及电网浪涌带来的尖峰电压 |
| 栅源电压     | Vgs      | 栅极驱动电压                                               | 典型值为±20V或±30V，外部驱动电压需要比栅极阈值电压Vgs(th)高出2V，以保证完全导通                  |

> **选型经验** 
  > - 低压系统(12V/24V)：若布线紧凑，寄生电感小的板子，选取1.3Vds，否则推荐选取至少1.7倍Vds；
  > - 48V系统(电信/服务器): Vds 不低于60V；
  > - 220V整流电路：Vds 不低于400V；
  > - 母线电压400V系统(微逆、工业电源)：Vds选择600-650V，提供1.5倍安全裕量，应对母线电压及电网浪涌；
  > - 三相380V系统(工业电源)：Vds选择800-950V；

### 2.2 电流和导通电阻

| 参数         | 符号    | 定义                                   | 选型要点                                                                         |
| ------------ | ------- | -------------------------------------- | -------------------------------------------------------------------------------- |
| 连续漏极电流 | Id      | MOSFET在特定壳温下能持续承受的最大电流 | 手册上通常给出在理想条件下测得的值，实际应用需要按工作时能达到的最大结温进行降额 |
| 脉冲漏极电流 | Idm     | MOSFET能承受的瞬时过载电流             | 常用于评估电机启动、电容充电等的瞬态工况                                         |
| 导通电阻     | Rds(on) | MOSFET完全导通时的漏-源等效电阻        | 直接决定导通损耗P=I² * Rds(on)，是大电流应用和效率提升的核心参数                 |

> 选型经验
> - Id：根据应用需求，选取1.3倍到1.5倍的Id值，以确保在正常工作温度下能够持续工作。
> - 不同封装Id的上限值不一样，可以根据实际应用选取合适的封装；

### 2.3 开关参数

| 参数               | 符号      | 定义                                         | 选型要点                                                         |
| ------------------ | --------- | -------------------------------------------- | ---------------------------------------------------------------- |
| 总栅极电荷         | Qg        | 使MOSFET从截止切换到完全导通所需要的总电荷量 | Qg越小，开关速度越快，开关损耗越小                               |
| 栅漏电荷(米勒电荷) | Qgd       | 影响米勒平台宽度                             | Qgd越小，开关所需要的时间越小，死区时间损耗越低                  |
| 输出电容           | Coss/Eoss | 影响开关节点电压变化速率的电容               | Coss中存储的能力Eoss在开关过程中会损失，是高频应用的关键损耗来源 |
| 输入电容           | Ciss      | 影响驱动电路负载                             | Ciss越大，驱动电路需要提供的峰值越大                             |

> 选型经验
> - 高频场景(>100KHz)：优先选择Qg < 20nC的低栅极电荷器件。
> - 品质因数FOM = Rds(on) * Qg 是综合评估导通和开关性能的常用指标，值越小越好。
> - 需要理解米勒平台形成原因及影响(实质上是在硬开时，Vds不等于0，导致开通过程中电容Cgd需要放电，从而使Vgs电压无法上升，形成平台。Cgd放电回路有两条，在Vgs达到阈值前，往母线电容放电，达到阈值后，MOS处于微导通状态，此时主要通过MOS本体放电)。

## 3.降额要求
详见[通用降额规范](../00_通用规范/降额规范.md)

|应力类型|降额系数|说明|
|----------|----------|------|
|漏源电压Vds| < 0.8 * V(BR)DSS|主流工程经验值|
|栅源电压Vgs| < 0.85 * Vgs(max)|至少需要比Vgs(th)高出2V|
|连续漏极电流Id| < 0.35~0.6 * Id(max)@100℃|按工作结温修正后评估|
|结温Tj| < 0.85 * Tj(max)| 工业环境取0.8|
|功率耗散Pd| < 0.8 * Pd(max)|@Tc|通过热设计管控|

> 补充说明
> - 对于Id(max)的值，需要在给定100℃的基础上按实际结温做线性调整。
> Id(max)_Corrected = Id(max)_Spec * (1 - (Tj_actual - Tj_spec) * k)
> 其中，Tj_actual为实际结温，Tj_spec为Id(max)时给出的结温，k为系数,K的取值如下：
> -- 低压SGT MOSFET(<100V),系数选0.3~0.5%/℃
> -- 高压SJ MOSFET(600V+)，系数选0.5~0.8%/℃
> -- SiC MOSFET，系数选0.2~0.4%/℃
> > 如：Id(max)_Spec = 60A @100℃， Tj_actual = 125℃，Tj_spec = 105℃，k = 0.5，Id(max)_Corrected = 60A * (1 - (125 - 105) * 0.5%) = 60 * 0.7 = 54A。
> - 在保证实际电流值 < 线性调整过的Id(max)的前提下，还需要测量实际结温，以确保实际结温满足MOSFET的结温降额要求，否则，应调整MOSFET规格。
> > 例如：Tj(max) = 150℃，Id(max) = 50A
> > Id_actual = 20A < 50*0.5 = 25A；但是此时，测量计算得到结温Tj_actual = 130℃ > 150℃ * 0.85 = 127.5℃，则不满足选型规范。

## 5.替代验证要求
|验证项目|要求|备注|
|----------|----------|------|
|静态参数差异| Rds(on) < ±15% <br> Vgs(th) ≤ ±20%|在相同 VGS 和 ID 条件下测量|
|动态参数差异|Qg ≤ ±20%，Ciss ≤ ±20%，Coss ≤ ±25%|在相同测试条件下对比|
|开关波形|关断电压尖峰差异 < 10%|双脉冲测试验证|
|热性能|相同工况下结温差 ≤ 5℃|在相同测试条件下对比|
|驱动兼容性|Vgs(th)差异不影响驱动能力|确保Vgs(th)至少要低于驱动电压2V|
|系统效率|满载效率差异≤0.3%|在相同测试条件下对比|

## 6.测试与判定方法
### 6.1 双脉冲测试(Double Pulse Test)
**测试目的：** 评估MOSFET在感性负载条件下的开关特性，包括开关损耗、米勒平台、电压尖峰、体二极管反向恢复。

**测试条件：** 
- 母线电压：额定工作电压的1.2倍。
- 负载电感：模拟实际电路中的感性负载
- 栅极驱动电阻：按实际设计值
- 测量节点：漏源电压Vds波形、栅源电压Vgs波形、漏源电流Id波形

**参数提取：**
- Eon：开通能量损耗
- Eoff：关断能量损耗
- Qrr：体二极管反向恢复电荷
- Vds_peak：关断电压尖峰

**判断标准：**
- Eon+Eoff符合损耗预算
- Qrr ≤ 手册给定的最大值(若有)
- Vds_peak ≤ 0.9 * V(BR)DSS
- 无寄生振荡或振铃幅度小于Vds的10%

### 6.2 稳态热测试
**测试目的：** 确认MOSFET在实际系统中的结温是否满足降额要求。

**测试条件：**
- 环境温度： 额定最高工作温度
- 负载条件： 额定满载和1.1倍过载
- 测试时长： ≥2H，温度稳定为准

**测试参数提取：**
- Tc: 外壳温度
- Tj_actual：实际结温 Tj_actual = Tc + RθJC × Pd
- Tj：额定结温

**判断标准：**
- 稳态下Tj_actual ≤ 0.85 * Tj(max)（工业电源取 0.80）
- 任意情况下Tj_actual ≤ Tj(max)

### 6.3 雪崩耐量测试（EAS）
**测试目的：** 评估 MOSFET 在关断感性负载时承受电压尖峰的能力。

**判断标准：**
- 重复性雪崩(EAR)： 必须满足设计条件
- 单次雪崩(EAS)： ≥ 电路实际储能水平 * 1.5
