# IGBT选型规范

## 1. 适用范围
- 工业电源（变频器、电机驱动、焊机、UPS）
- 光伏逆变器
- 储能变流器等产品中的 IGBT 分立器件（TO‑247、TO‑220、TO‑3P）及模块（6 单元、PIM、IPM）

## 2. 选型核心与优先级矩阵
IGBT的选型是多个参数权衡的结果，其中电压等级、电流等级、工作频率和热性能是四个最核心的维度。
| 产品类型                                  | 第一优先级                                           | 第二优先级               | 第三优先级                     |
| ----------------------------------------- | ---------------------------------------------------- | ------------------------ | ------------------------------ |
| 工业电机驱动、变频器<br>(< 8KHz)          | 电压等级<br>通态压降                                 | 电流等级<br>热阻         | 开关损耗<br>短路耐受能力       |
| 高频工业电源(PFC、焊机、UPS)<br>(> 20KHz) | 电压等级<br>开关损耗                                 | 通态压降<br>并联均流能力 | 续流二极管恢复特性<br>封装形式 |
| 通用工业电源）<br>(中频8-20KHz)           | 电压、通态压降、开关损耗同等重要（需仿真确定主导项） | 热阻、电流等级           | 其他                           |

## 3. 不同IGBT技术系列对比
| IGBT系列                        | 栅极结构       | 典型Vce(sat)@额定电流 | 开关损耗 | 适用频率范围 | 短路耐受           | 典型应用                                            |
| ------------------------------- | -------------- | --------------------- | -------- | ------------ | ------------------ | --------------------------------------------------- |
| 非穿通(NPT)                     | 平面栅         | 较高(2.0~2.5V)        | 中等     | <10KHz       | 强(10us)           | 工业电机驱动、通用变频器(老设计)                    |
| 平面栅-场截止(Planar-FS)        | 平面栅         | 中等(1.7~2.0V)        | 中等     | <15KHz       | 5~10us             | 低成本工业驱动、部分光伏、UPS（逐步淘汰）           |
| 沟槽栅-场截止(Trench-FS)-标准型 | 沟槽栅         | 低(1.45~1.7V)         | 中低     | 2-30KHz      | 5~8us              | 通用变频器、工业电源、光伏逆变器、伺服              |
| 沟槽栅-场截止(Trench-FS)-高速型 | 沟槽栅         | 中低(1.5~1.8V)        | 极低     | 20-60KHz     | 弱1~3us            | 高频焊机、UPS、充电桩、光伏(高频)                   |
| IGBT7 (T7 / S7 / H7)            | 微沟槽栅       | 极低(1.0~1.5V)        | 极低     | 20-60KHz     | T7/S7：8us，H7：无 | 高性能工业电源、光伏/储能、服务器电源、电动汽车充电 |
| IPM（智能功率模块）             | 多为 Trench‑FS | 低 (1.5~1.8V)         | 中低     | 2~20 kHz     | 集成保护           | 电机驱动、空调、风扇、家电（紧凑设计）              |
> - NPT 和 Planar‑FS 属于较老技术，新设计不建议优先选用，除非成本极端敏感。
> - Trench‑FS 标准型 是目前工业驱动和通用电源的主流选择，兼顾导通损耗与开关损耗。
> - Trench‑FS 高速型 牺牲部分短路能力换取极低开关损耗，适用于 >20 kHz 的硬开关拓扑。
> - IGBT7 是最新一代，具有极低的导通压降和开关损耗，同时部分型号保留短路能力，代表未来方向。
> - IPM 将 IGBT、驱动、保护集成，适合简化设计和缩短开发周期。

## 4. 关键参数详解速查表
参数|符号|物理含义|选型要点|
|:---|:---:|:---|:---|
集电极-发射极电压|Vces|截止态最大耐压|稳态工作电压峰值≤80%*Vces<br>380Vac整流后推荐1200V器件
连续集电极电流|Ic@Tc|规定壳温下的连续电流能力|必须使用Tc = 100℃或 Tc = 125℃下的值，不可用25℃下的值|
饱和压降|Vce(sat)|饱和导通时，集电极-发射极电压|低频应用优先选低值；与开关损耗权衡|
开关损耗|Eon/Eoff|开通和关断过程中的功率损耗|主要由开关电压和开关电流决定，高频应用优先选低值，需按实际电压、电流、温度折算|
结温|Tj|芯片工作温度|稳态Tj ≤ 0.85*Tj(max)|
热阻|Rth_JC|热量从芯片传导到外壳的阻力|越小越好，用于结温估算|
短路耐受时间|Tsc|短路时允许的持续时间|电机驱动等要求 Tsc≥10us<br>通用电源可放宽至5us|
续流二级管恢复|Trr/Qrr|内部二极管反向恢复特性|硬桥、PFC硬开关中影响损耗及EMI|

## 5.降额要求
|应力类型|降额系数|具体取值规则|
|:---|:---:|:---|
电压V<sub>CES</sub>	| ≤ 0.8|例如380V母线(峰值540V)-->选680V以上-->标准1200V等级|
电流 I<sub>C</sub>| ≤ 0.5 |1.初始选型I_load_max ≤ 0.5 * Ic@100℃<br>强制风冷良好-->放宽至0.65<br>自然冷却或高环温-->收紧至0.4-0.45<br>IGBT模块-->起始按0.6-0.7|
结温T<sub>j</sub>|≤ 0.85 * T<sub>j(max)</sub>| T<sub>j(max)</sub> = 150°C → 稳态 ≤ 127°C|
功率耗散P<sub>tot</sub>|≤ 0.80 * P<sub>tot(max)</sub>|通过散热设计保证
短路耐受|实测 t<sub>sc</sub> ≥ 手册最小值 × 0.9|电机驱动类必须验证|

## 9.替代验证要求
验证项目|允许差异|测试条件
|-|:-|:-|
|V<sub>CE(sat)</sub>|≤ ±15%|相同 I<sub>C</sub>、V<sub>GE</sub>、结温
|E<sub>on</sub> + E<sub>off</sub>|≤ 原型号 × 1.10|相同母线电压、负载电流、驱动电阻、结温
|稳态结温（实测）|≤ 原型号 + 8℃ |相同散热条件、环境温度、负载
|t<sub>sc</sub>|≥ 原型号 × 0.9|相同母线电压、V<sub>GE</sub>
|系统效率|满载差异 ≤ 0.3%|同输入输出条件|

## 10.测试与判定方法
测试项目|方法简述|判定标准
|-|:-|:-|
静态导通压降|恒流源施加额定 I<sub>C</sub>，测 V<sub>CE</sub>|≤ 手册最大值|
开关损耗(双脉冲)|双脉冲平台，捕获 V<sub>CE</sub>, I<sub>C</sub> 积分|E<sub>on/off</sub> ≤ 1.15 × 手册典型值|
热阻(结-壳)|电学法(降温曲线)|≤ 手册最大值|
短路能力|直接短路负载，测短路电流及时间|不损坏，且 t<sub>sc</sub> ≥ 手册最小值|
绝缘耐压(模块)|施压AC 2.5kV / 1min|无击穿，漏电流合格|
