# 二极管选型规范
## 1. 适用范围
本规范适用于以下产品中的二极管选型：
- 微型逆变器：输入反接保护、升压级整流、钳位电路、辅助电源整流
- 服务器电源：PFC 级升压二极管、钳位电路、输出整流、辅助电源
- 工业电源：输入整流桥、输出整流、续流二极管、钳位吸收电路

涵盖的二极管类型：

## 2. 关键参数与优先级(按产品类型)
| 产品类型   | 第一优先级                         | 第二优先级              | 第三优先级                 |
| :--------- | :--------------------------------- | :---------------------- | :------------------------- |
| 微型逆变器 | Vf(考虑导通损耗)<br>Trr/Qrr        | 结温、热阻              | 漏电流Ir(高温下)、封装尺寸 |
| 服务器电源 | Vf(考虑导通损耗)<br>Trr/Qrr        | 封装、并联均流能力(SBD) | 成本、长期供货             |
| 工业电源   | 鲁棒性(浪涌电流IFSM)、高温漏电流Ir | 结温、封装散热          | 长期供货、安规             |

> 简述
> - 微型逆变器要求低压降效率和高结温耐受(户外散热差)
> - 服务器电源对反向恢复导致的开关损耗极其敏感，尤其是在图腾柱 PFC 等高频硬开关应用中
> - 工业电源优先考虑抗浪涌和高温稳定性

## 3. 关键参数详解
### 3.1 电压参数
| 参数             | 符号 | 定义                     | 选型要点                                     |
| :--------------- | :--- | :----------------------- | :------------------------------------------- |
| 反向重复峰值电压 | Vrrm | 可重复施加的最高反向电压 | 必须大于电路中出现的最高反向电压，并留足裕量 |
| 反向浪涌电压     | Vrsm | 非重复性瞬态反向电压     | 用于评估电网浪涌、开关尖峰等异常情况         |

> 选型经验
> - 输入整流桥：Vrrm ≥ 1.5 * 输入峰值电压
> - PFC升压二极管：Vrrm ≥ 1.2 * 母线电压(考虑尖峰)
> - 钳位二极管：Vrrm ≥ 1.3 * 钳位电压

### 3.2 电流参数
| 参数         | 符号   | 定义                     | 选型要点                                     |
| :----------- | :----- | :----------------------- | :------------------------------------------- |
| 平均整流电流 | IF(AV) | 直流或正弦半波平均值     | 按通过电流的波形因数折算有效值，并降额使用   |
| 正向浪涌电流 | IFSM   | 非重复性瞬态正向过载电流 | 用于评估开机电容充电、负载短路等瞬态耐受能力 |
| 重复峰值电流 | Irrm   | 可重复的峰值反向电流     | 用于反激钳位等周期性尖峰场景                 |

> IFSM 的重要性：
> 工业电源中浪涌可能高达几百安培，必须保证IFSM大于实测浪涌电流 * 1.2

### 3.3 正向特性
| 参数                 | 符号   | 定义             | 选型要点                                                                                      |
| :------------------- | :----- | :--------------- | :-------------------------------------------------------------------------------------------- |
| 正向压降             | Vf     | 正向导通电压     | 必须小于等于最大工作电压，VF 越小，导通损耗越低。肖特基最低（0.3-0.6V），SiC 略高（1.2-1.7V） |
| 正向电流压降温度系数 | ΔVF/ΔT | VF随温度的变化率 | 肖特基为负（易热失控），SiC和FRD 为正(利于均流并联)                                           |

> VF的工程权衡：
> - 追求极致效率：低压选SBD，高压选SiC SBD
> - 成本敏感：FRD（高压）或普通SBD（低压）
> - 高温环境或并联应用：正温度系数器件（SiC、FRD）更安全

### 3.4 开关特性（**最关键**）
| 参数         | 符号                | 定义                                                                                                       | 选型要点                                                           |
| ------------ | ------------------- | ---------------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------ |
| 反向恢复时间 | Trr                 | 从正向导通转为反向截止时，PN结重建势垒区所需要花费的时间                                                   | Trr越小，开关损耗越低。高频硬开关必须关注（开关周期必须远大于Trr） |
| 反向恢复电荷 | Qrr                 | 反向恢复时间Trr内，PN结重建势垒区所花费的时间段内流过的电荷总量 $$ Q_{rr} = \int_{t0}^{t1}i_{rr}(t)\,dt $$ | Qrr直接决定反向恢复损耗：$$ P_{rr} = Q_{rr} * V_{rrm} * f_{sw} $$  |
| 软恢复因子   | $$ S = t_f / t_d $$ | 恢复波形尾部与下降段时间之比                                                                               | 软恢复(S>1),可降低EMI，减少振铃                                    |

> **选型注意事项：**
> - 对于高频硬开（CCM PFC、反激、硬开关全桥）拓扑，必须选择Trr及Qrr都足够小的二极管（超快恢复或SiC）
> - Qrr随温度升高而增加，必须使用实际工作温度下的Qrr值进行计算，避免选择错误的二极管
> - 数据手册给出的Qrr通常是在特定的di/dt、温度和电流下测试的，实际设计要留有裕量
> - 允许的最大Trr由开关频率和死区时间决定，一般为Trr < 0.1 * T_sw，以保证在一个周期内完成反向恢复
> - 软开关拓扑（LLC、DCM）对Trr不敏感，可以选择较慢的二极管


### 3.5 热特性与漏电流
| 参数       | 符号       | 定义                             | 选型要点                                                                                        |
| ---------- | ---------- | -------------------------------- | ----------------------------------------------------------------------------------------------- |
| 结温       | Tj         | 二极管工作时的PN结温度           | 必须大于等于最大工作温度，且留足裕量。工业/户外产品要求Tj(max) ≥ 175℃，微逆建议优选175℃的二极管 |
| 热阻       | RθJC, RθJA | PN结到外壳/环境的热阻            | 影响温升，需结合散热设计评估                                                                    |
| 反向漏电流 | Ir         | 指在特定反向电压和温度下的漏电流 | 肖特基IR随温度指数上升，高温下可能导致热失控                                                    |

> **选型注意事项：**
> - 肖特基的Ir在25℃时为几uA，但在125℃时可能为数mA
> - 高温高压应用中，尤其注意漏电流带来的损耗，避免引发正反馈热失控，必要时选用高压肖特基或改用 FRD / SiC

## 4. 降额要求
| 应力类型             | 降额系数                       | 说明                                        |
| -------------------- | ------------------------------ | ------------------------------------------- |
| 反向重复峰值电压VRRM | ≤ 0.80 × VRRM                  | 常规应用；高可靠性工业电源取 0.70           |
| 平均整流电流 IF(AV)  | ≤0.50~0.70 × IF(AV) @ Tc=100°C | 类似于MOSFET，降额系数取决于实际的工作温度  |
| 正向浪涌电流 IFSM    | ≤0.60 × IFSM                   | 非重复性，仍须保留裕量防止早期失效          |
| 结温 Tj              | ≤0.85 × Tj(max)                | 高可靠性取 0.80；肖特基须额外关注高温漏电流 |
| 功率耗散 Pd          | ≤0.80 × Pd(max)                | 通过热设计控制                              |

## 6. 替代验证要求
| 验证项目     | 要求                     | 备注                       |
| ------------ | ------------------------ | -------------------------- |
| 静态参数差异 | VF ≤ ±10%<br>IR ≤ ±30%   | 高温下的IR是差异敏感项     |
| 动态参数差异 | Trr ≤ ±15%<br>Qrr ≤ ±20% | 须在同一双脉冲平台对比     |
| 浪涌耐受     | IFSM ≥ 原型号 × 0.9      | 非重复性差异可接受较小     |
| 热性能       | 相同工况下结温相差 ≤ 8℃  | 通过热阻 RθJC 结合实测验证 |
| 系统效率     | 满足效率差异 ≤ 0.3%      | 综合评估开关+导通损耗      |

## 7. 测试与判定方法

### 7.1 反向恢复参数测试(Trr，Qrr)
**测试电路：**
双脉冲测试平台（同MOSFET双脉冲）

**测试步骤：**
1. 配置半桥电路，待测二极管作为下管（或直接使用 MOSFET 体二极管对比）

2. 第一个脉冲：建立正向电流 IF

3. 第二个脉冲：使待测二极管承受反向电压

4. 捕获二极管电流波形（使用电流探头或同轴分流器）

**参数提取：**
- Trr：电流从过零点到恢复至反向漏电流 ±10% 的时间
- Qrr：对反向恢复电流波形积分（从过零到恢复结束），单位 nC / µC

**判断标准：**
- 实测 trr ≤ 1.15 × 手册最大值
- Qrr ≤ 手册典型值 × 1.5（或内部设定的上限）

### 7.2 正向压降VF测试
**测试方法：**
- 使用直流电源 + 电阻负载 / 电子负载，施加额定 IF（如 5A / 10A / 15A）
- 同时测量二极管两端电压（四线开尔文连接消除导线压降）
- 记录不同结温下的 VF（使用烘箱或热流平台控制温度）
**判定标准：**
- 25°C 下 VF ≤ 手册最大值
- 125°C 下 VF ≤ 1.10 × 25°C VF（肖特基负温度系数，VF 下降，此标准不适用；对 FRD/SiC 适用）

### 7.3 高温漏电流IR测试
**测试方法：**
- 将二极管置于恒温箱（Tj = 125°C 或 150°C）
- 施加 VRRM × 0.8 的反向电压
- 测量漏电流（使用皮安表或高精度万用表）

**判定标准：**
- IR @ 125°C ≤ 手册最大值
- 若 IR × VR 产生的热耗散导致结温再升高超过 5°C，则不合格（热失控风险）


### 7.4 浪涌电流IFSM测试
**测试方法(仅型式试验)：**
- 使用浪涌发生器，施加 8.3ms 或 10ms 半正弦波电流，幅值 = 额定 IFSM × 0.9
- 测试前后测量 VF 和 IR，变化不应超过 10%

**判断标准：**
- 试验后无可见损伤，VF 变化 ≤ +5%，IR 变化 ≤ +100%

## 9.不同拓扑的选型快速指南
| 拓扑/应用                  | 推荐二极管类型                   | 关键关注点  | 不推荐类型               |
| -------------------------- | -------------------------------- | ----------- | ------------------------ |
| 反激输出整流(低压，< 30V)  | 肖特基SBD                        | VF，IR      | 快恢复(VF太高)           |
| 反激输出整流(高压，≥ 100V) | 超快恢复FRD                      | Trr,Qrr     | 肖特基(耐压或IR不够)     |
| CCM PFC 升压               | SiC SBD 或 超快恢复              | Qrr，软恢复 | 普通快恢复               |
| 图腾柱 PFC 慢管            | SiC SBD                          | 零反向恢复  | 任何有 Qrr 的器件        |
| LLC 谐振（体二极管或并联） | 任意（不经历硬恢复）             | VF，成本    | 无特殊限制               |
| 钳位吸收（RCD）            | 超快恢复                         | trr，耐压   | 普通整流                 |
| 输入反接保护               | 肖特基（低压）或 MOSFET+栅极驱动 | VF 低       | 压降大、功率损耗大       |
| 工业输入三相整流桥         | 标准整流二极管模块               | IFSM，VRRM  | 任何单管（除非功率很小） |
