# 1、算力单元选型规范































## 1.1 峰值算力

- **定义：** 衡量AI芯片的绝对处理能力
- **单位：** TOPS(Tera Operations Per Second)、TFLOPS(Tera Floating Point Operations Per Second)
- **精度：** FP32、FP16、FP4、INT8、INT4

**单位维度**|TOPS|TFLOPS
:---|:---|:---|
**全称**|Tera Operations Per Second|Tera Floating Point Operations Per Second|
**核心区别**|统计任何操作的总次数(含整数、逻辑等)|仅统计浮点运算的次数|
**典型精度**|INT8、INT4(整数精度)|FP32、FP16、FP4(浮点精度)|
**典型场景**|AI推理、图像处理|科学计算、模型训练、3D渲染|

- TOPS全称为Tera Operations Per Second，代表处理器每秒可进行一万亿次（10¹²）操作，统计的是所有操作（包含整数运算、逻辑运算等）。
- TFLOPS全称为Tera Floating Point Operations Per Second，代表处理器每秒可进行一万亿次浮点运算（10¹²），统计的是浮点运算次数。也是GPU算力的传统指标。

**精度维度**|完整名称|特性|常见用途
|---|---|---|---|
FP32|32位浮点数|高精度、数值范围广，资源消耗大|模型训练、需要高精度的科学计算|
FP16|16位浮点数|精度与速度的平衡，现代GPU/TensorRT广泛采用|深度学习推理，兼顾速度与精度|
FP4|4位浮点数|超低精度但保留浮点结构，能实现高吞吐量|NVIDIA Blackwell架构主推，端侧大模型推理|
INT8|8位整数|显著缩小模型体积、提升推理速度|AI推理的标准精度，资源受限场景|
INT4|4位整数|极致压缩，资源占用最低|边缘设备中对精度要求较低的场景|


> 对比算力时，一定得结合精度，不能只看数值。

## 1.2 大模型专属内存

- **定义：** 随机存取存储器（RAM），是计算机系统中临时存储数据和程序的硬件组件，用于与CPU、GPU等计算核心进行高速数据交换
- **核心特征：**
    - **临时性：** 断电后所有数据会立即丢失（与硬盘或SSD等永久存储不同）。
    - **高速性：** 读写速度远高于硬盘/SSD，通常可达几十GB/s到TB/s级别，目的是尽可能匹配计算核心的处理速度，避免“饥饿”。
    - **地址可随机访问：** CPU或GPU可以直接访问内存中的任意一个字节，无需像硬盘那样顺序查找。

-**参数指标：**
|参数指标|核心定义|对AI轻推理的影响|快速决策指南
|---|---|---|---|
|**容量**|内存可同时存放的数据总量（单位：GB）|“临时工作台” 的大小。容量不足，模型和数据就无法完全在内存中运行，系统会变得非常慢| **够用就好：** 根据预计运行的模型大小选择。建议至少保留20%的余量，应对模型和数据的动态增长需求|
|**带宽**|内存与计算核心（如GPU/NPU）之间每秒能传输的数据量（单位：GB/s）|“通往大脑的高速公路” 的宽度。带宽越高，数据喂给AI计算单元的速度越快，能有效减少计算核心的等待时间| **越快越好：** 对AI推理的吞吐量和延迟影响巨大。超大模型推理的优先考虑因素，高带宽是关键
|**延迟**|内存响应CPU指令的等待时间（通常表示为CL等）|“路口红灯的等待时间” 。通常用CL值表示，数值越小，内存反应越快，能提升系统响应的敏捷性| **不是首要：** 对于大规模并行计算的AI任务，内存带宽是主要矛盾，时序对整体推理速率影响较小
|**功耗**|内存运行时消耗的电能（单位：瓦特W）|对于机器人、手机等电池供电设备，功耗直接决定了设备的续航和散热设计的难度|**能效优先：** 在保证性能的前提下，选择功耗更低的内存技术（如LPDDR系列），是移动端和边缘端部署的关键
|**类型**|内存的物理结构和功能，如DDR4/5, LPDDR5X, HBM3e等|内存的“门派”和“等级”，决定了上述各项指标的基础水平和适用场景。|**场景导向：** 根据应用场景（服务器/移动设备/机器人）和性能需求，从下表中选择最匹配的内存类型。

**主流内存类型详解：** DDR vs LPDDR vs HBM
特性|DDR(以DDR5为例)|LPDDR(LPDDR5X为例)|HBM(以HBM3e为例)
|:---:|:---:|:---:|:---:|
|核心定位|PC、服务器的通用内存，性能与成本的均衡|手机、笔记本等移动设备，尤其注重低功耗|高性能计算、AI训练的专属内存，追求极致带宽
|典型容量|8~64GB|4-32GB|16GB-144GB|
|总线位宽|64位单通道|32/64/128位(可扩展)|1024位(每堆栈)|
|峰值带宽|约51.2GB/s(单模块)|85.6~171.2GB/s|8192GB/s
|功耗特点|3~6W|4~8W|30~50W|
|工作电压|1.1V|0.9V|1.1~1.2V|
|能效GB/s /W|~10GB/s/W|~20-40GB/s/W|~160-270GB/s/W|
|延迟(CL值)|CL40 ~ 48（高延迟）12ns左右|CL36 ~ 42（中等）8ns左右|极低（得益于堆叠近核，但通常不公开CL，以纳秒计约10-20ns）|
|散热需求|被动散热或小风扇(热源多)|被动散热即可|必须主动散热(水冷或风冷)|
|成本|低|中等|极高
|对AI轻推理的影响|不推荐：功耗偏高，带宽不够突出，封装大|首选：能效比最优，容量满足7B~13B模型，带宽足以支撑流畅推理(>30 tokens/s)|过杀：功耗、成本、散热均不适合轻推理，且封装不适用于移动机器人|

**针对机器人算力背包的选型结论：** 选LPDDR5X，带宽≥100GB/S，容量≥12GB
|需求|推荐内存类型|关键参数门槛|
|:---:|:---:|:---:|
|运行7B-13B大模型|LPDDR5X|容量≥12GB<br>带宽≥100GB/s|
追求长续航（>8小时）|LPDDR5X|能效 > 20 GB/s/W，整机内存功耗 < 5W|
|需要实时视觉 + 大模型（多模态）|LPDDR5X（高带宽版本）|带宽 ≥ 170 GB/s（如128位总线）|
|国产化替代，满足自主可控|国产 LPDDR4X/5（长鑫、兆易创新等）|性能接近主流，但需确认软件兼容|
|预算有限，做原型验证|二手 Jetson Orin NX（64位 LPDDR5）|带宽约 68 GB/s，可跑 3B 模型|

> 选型关键
> - 容量门槛 ≥ 12GB (可跑7B~13B INT4模型)
> - 带宽门槛 ≥ 100GB/s (确保对话流畅 >30 tokens/s)
> - 能效优先：LPDDR5X，整机内存功耗 <5W，长续航
> - 多模态刚需：选128位总线，带宽 ≥170 GB/s

## 1.3 能效与散热
用TFLOPS/W或TOPS/W来评估，意味着每消耗1W电能可以完成多少计算任务。高效能配合高效的散热方案是芯片能否稳定满血运行的关键。

### 1.3.1 能效
- **定义：** 每消耗1瓦特（W）功率，能产出多少有效计算性能。
- **常用单位：** TOPS/W（INT8推理），TFLOPS/W（FP16训练/推理）
>示例
> - 某芯片 INT8 算力 100 TOPS，功耗 25W → 能效 = 4 TOPS/W
> -  另一芯片 INT8 算力 200 TOPS，功耗 100W → 能效 = 2 TOPS/W
> **虽然后者绝对算力更高，但能效更低，意味着它每完成1次运算“浪费”了更多电能转化为热量**

**对机器人的影响：** 
- 机器人是电池供电，能效直接决定 续航时间。
- 低能效意味着相同电池容量下，背包只能短时间工作，或需要背负更重的电池。
- 高能效允许在有限散热条件下维持更高算力（不降频）。


### 1.3.2 散热
- **定义：** 散热是把芯片工作时产生的热量从芯片内部传递到外部环境，保持结温（TJ）在安全范围内（通常 <85~100°C）。
- **关键概念：** 
  - 热阻（θJA，θJC）：热量从芯片结到环境或外壳的阻力，单位°C/W。
  - 热设计功耗（TDP）：系统散热方案必须能持续带走的最大热量（单位W）。
  - 结温（TJ）：芯片工作时的温度，单位℃。

- **机器人背包的散热挑战：**
  - 空间极小，无法放置大型风扇或水冷。
  - 移动环境可能积灰、震动、密闭安装。
  - 重量敏感，散热器（均热板、热管、鳍片）不能过重。

- **常见散热方案：**
  - 被动散热：仅靠导热垫+金属外壳+自然对流（适用于 <15W TDP）。
  - 主动风冷：小型轴流风扇（适用于 15~60W TDP，但有噪音、灰尘问题）。
  - 均热板+导热管：将热量传导到大面积外壳（适用于 40~130W，如 BotPack B5）。


维度|能效|散热
|----|----|----|
定义|每瓦功率产出的算力(TOPS/S)|将芯片热量传递到环境的能力
核心指标|TFLOPS/W，TOPS/W|TDP(W),热阻(℃/w),结温(℃)|
对机器人的影响|决定续航、电池重量|决定能否持续满血运行、安全工作温度|
优化方向|选择高能效芯片/内存|增大散热面积、优化风道、使用热管|


**如何评估能效与散热？**
- 确定所需持续算力
- 查芯片能效，比如 NVIDIA Orin NX 能效约 4 TOPS/W（INT8），则 50 TOPS → 功耗 ≈ 12.5W。
- 查内存能效，LPDDR5X 提供 100 GB/s 带宽，功耗 ≈ 4W。
- 其他功耗，SSD、WiFi、5G、传感器）≈ 3W。
- 总功耗 ≈ 12.5 + 4 + 3 = 19.5W。
- 检查散热方案：19.5W 在紧凑背包中通常需要 主动风冷（小型风扇） 或 大面积极冷外壳。


## 1.4 架构与生态

### 1.4.1架构：硬件层面的“骨架和神经系统”
- 1.通用范式：异构计算(所有AI SoC的共同特征)
   - 定义：将CPU、GPU、NPU、DSP、ISP等不同功能的计算单元集成在同一芯片上，各司其职。
    - 目的：兼顾通用计算、AI加速、数字信号处理等，提高能效比。
    - 代表：NVIDIA Jetson Orin、高通Snapdragon、华为昇腾、地瓜S600。
- 2.机器人特化：大小脑协同（部分厂商的差异化架构）
    - 定义：在异构计算基础上，将“大脑”（高算力AI推理）与“小脑”（实时运动控制，通常由MCU或锁步CPU实现）深度融合，共享低延迟总线或内存。
    - 独特价值：满足机器人对硬实时控制（毫秒级响应）与大模型推理的双重需求，减少通信开销。
    - 代表：地瓜机器人S600（单SoC集成“大小脑”）。
- 3.具体IP核：专有计算单元（各厂商的私有加速器）
    - 定义：异构SoC内部专门用于某类运算的加速模块，通常是NPU或矩阵乘单元。
    - 不是独立架构，而是异构计算的组成部分。
    - 代表：英伟达：Tensor Core，华为：达芬奇NPU，高通：Hexagon NPU，地瓜：BPU
>**三者关系：** 异构计算是“骨架”，大小脑协同是“姿态调整”，专有单元是“肌肉”。所有现代AI芯片都采用异构计算；大小脑协同是部分机器人芯片的增强设计；专有单元每家都有，名称不同但功能类似。

### 1.4.4 选型决策要点
- 追求最短落地周期、最低风险 → 英伟达（生态最成熟）
- 希望探索“大小脑”新架构，愿意投入研发 → 地瓜机器人
- 必须国产化、数据不出境 → 华为昇腾
- 极端重视续航、低功耗 → 高通（能效优势）
- 已有机器人本体，需要外挂算力背包 → 星源智（集成方案）
