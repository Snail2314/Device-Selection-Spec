# 器件选型规范

## 适用范围
本仓库存放硬件器件选型规范，主要用于微型逆变器产品选型

## 如何使用
- 按器件类型查找对应 `.md` 文件
- 所有规范遵循 [通用规范](./00_通用规范/) 中的降额、归一化等要求

## 维护方式
Markdown + Git，每个器件独立文件，按需补充
